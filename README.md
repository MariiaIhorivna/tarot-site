# Tarot Website

A responsive website developed for an individual tarot reader to present her services and establish an online presence.

## Technologies

- **HTML5** — page structure
- **CSS3** — styling and responsive design
- **JavaScript (Vanilla JS)** — interactivity and dynamic content rendering
- **Fetch API** — asynchronous data loading from JSON files

## Features

- Dynamic content loading from JSON files
- Asynchronous data fetching using the Fetch API
- Responsive design for different screen sizes
- Interactive UI elements

## Project Purpose

A freelance web development project created for an individual service provider.
